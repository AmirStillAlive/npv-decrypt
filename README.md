# رمزگشایی کانفیگ NPV Tunnel | NPV Decrypt

فایل‌های کانفیگ `.npvt` و `.npvs` که اپ **NPV Tunnel / NapsternetV** می‌سازد را باز کنید. دو راه دارید: ابزار خط فرمان پایتون، یا صفحه وبی که **کاملا داخل مرورگر** کار می‌کند و فایل شما به هیچ سروری نمی‌رود.

**وب‌اپ آنلاین:** https://amirstillalive.github.io/npv-decrypt/

---

## ماجرا چیست؟

کانفیگ‌هایی که در کانال‌های تلگرامی با پسوند `.npvt` پخش می‌شوند، به‌ظاهر رمزنگاری شده‌اند. ولی این رمز در عمل محافظ خاصی نیست: کلید اصلی هیچ‌جا وجود ندارد و به‌جای آن یک **AES-128 در حالت CTR با کلید white-box** پیاده شده، یعنی جدول‌های رمز داخل خود اپ جاسازی شده‌اند. چون همین جدول‌ها عمومی‌اند، باز کردن فایل بدون هیچ کلید مخفی ممکن است.

این مخزن همان رمزگشایی را پیاده می‌کند تا ببینید دقیقا چه چیزی دست‌تان می‌رسد: سرور کیست، ترافیک از کجا رد می‌شود و چه تنظیماتی داخل کانفیگ است.

## استفاده: نسخه خط فرمان (پایتون)

```bash
python decrypt_npvt.py <پوشه یا فایل ورودی> [پوشه خروجی]
```

به هیچ کتابخانه خارجی نیاز ندارد (فقط استاندارد پایتون). جدول‌ها در فایل `npv_tables.json` کنار اسکریپت است. خروجی هر فایل یک `.txt` با JSON خواناست.

```bash
python verify.py <پوشه حاوی .npvt>    # هش SHA-256 خروجی هر فایل را چاپ می‌کند
```

## استفاده: نسخه خط فرمان (NPVS)

```bash
python npvs.py <پوشه یا فایل NPVS> [پوشه خروجی]
python npvs.py config.npvs            # فقط چاپ در خروجی
python npvs.py . out/                # رمزگشایی یک پوشه
python npvs.py locked.npvs --password 'ramz'
```

فایل‌هایی که سازنده برایشان رمز گذاشته بدون رمز باز نمی‌شوند؛ پیام خطا هشدار می‌دهد و اگر سازنده پیامی گذاشته باشد همان را هم نشان می‌دهد.

## استفاده: وب‌اپ (GitHub Pages)

سورس اپ در پوشه `web` است (React به همراه Tailwind نسخه ۴). خروجی build در پوشه `docs` می‌نشیند و GitHub Pages هم از همان پوشه بالا می‌آید.

```bash
cd web
npm install
node node_modules/vite/bin/vite.js build   # خروجی در ../docs
```

همه‌چیز در مرورگر اجرا می‌شود: جدول‌های رمز داخل خود باندل جاوااسکریپت است و فایل شما هیچ درخواست شبکه‌ای نمی‌سازد. اگر اینترنت را قطع کنید هم کار می‌کند.

**تست پاریتی (پایتون در برابر جاوااسکریپت):**

```bash
node web/test/verify.mjs <پوشه حاوی .npvt>
python verify.py           <پوشه حاوی .npvt>
# هر دو باید برای هر فایل هش SHA-256 یکسان بدهند
```

وضعیت فعلی: **هر ۱۴ فایل نمونه، خروجی بایت‌به‌بایت یکسان.**

## فرمت `.npvt`

```
NPVT1\n<base64>,<base64>,<base64>
```

هر توکن base64 یک بلاک است:

| بخش | طول | توضیح |
|---|---|---|
| counter/nonce | ۱۶ بایت | مقدار اولیه شمارنده CTR (big-endian) |
| ciphertext | باقی‌مانده | با XOR کردن کی‌استریم خروجی جدول‌های white-box باز می‌شود |

هسته رمز یک تبدیل ۱۶ بایتی با جدول‌های `tyBoxes`، `mbl`، `xorTable` و `tboxesLast` است. پیاده‌سازی از سورس Go پروژه [Pantegnos](https://github.com/FrontierTM/Pantegnos) (پروانه MIT) استخراج و به پایتون و جاوااسکریپت پورت شده است.

**نتیجه روی نمونه‌ها:** هر ۱۴ فایل `.npvt` باز شدند: کانفیگ‌های V2Ray (شامل VMess و VLESS روی TLS و WebSocket) روی سرورهای Cloudflare و اروپا، به‌همراه `lockConfig` کانفیگ‌ساز.

## درباره فایل `.npvs`

برخلاف `.npvt`، فایل `.npvs` یک پاکت کامل با سرآیند JSON است:

```
"NPVS" | نسخه (۱ بایت) | طول سرآیند (۴ بایت BE) | سرآیند JSON
| nonce (۱۲ بایت) | طول بدنه (۴ بایت BE) | بدنه | امضا (۶۴ بایت)
```

سرآیند مشخص می‌کند کلید از کجا می‌آید:

| روش | KDF | رمز لازم؟ |
|---|---|---|
| `appKey` | `wbaes-ctr-sha256` سپس ChaCha20-Poly1305 | **نه، کاملا آفلاین** |
| `passphrase` | `pbkdf2-hmac-sha256` سپس ChaCha20-Poly1305 | بله |
| `recipients` | ECDH | به کلید خصوصی گیرنده نیاز دارد |

مسیر `appKey` همان الگوی `.npvt` را دارد: کلید نهایی داخل جدول‌های white-box خود اپ است، پس هر کسی که جدول‌ها را داشته باشد می‌تواند بدون رمز و بدون اینترنت فایل را باز کند.

**نتیجهٔ عملی:** بیشتر فایل‌های `.npvs` که در کانال‌ها پخش می‌شوند بدون رمز باز می‌شوند. فقط فایل‌هایی که سازنده برایشان رمز گذاشته به همان رمز نیاز دارند که باید از خودش بگیرید.

پیاده‌سازی: `npvs.py` (پایتون) و `web/src/lib/npvs.js` (مرورگر). هر دو از یک سورس مشترق آمده‌اند و آزمون پاریتی نشان می‌دهد خروجی‌شان بایت‌به‌بایت یکی است.

## ساختار مخزن

```
decrypt_npvt.py         ابزار خط فرمان برای .npvt
npv_tables.json         جدول‌های white-box نسخهٔ .npvt
npvs.py                 ابزار خط فرمان برای .npvs
npvs_tables.json        جدول‌های white-box نسخهٔ .npvs
verify.py               تست پاریتی پایتون برای .npvt
test_npvs.py            آزمون‌های NPVS در پایتون
web/                    سورس اپ React (با Vite و Tailwind نسخه ۴)
web/src/lib/npvs.js     رمزگشایی NPVS در مرورگر
web/test/verify.mjs     تست پاریتی جاوااسکریپت برای .npvt
web/test/npvs-parity.mjs  آزمون‌های NPVS و پاریتی با پایتون
web/og/                 منبع تصویر پیش‌نمایش شبکه‌های اجتماعی
tools/                  بسته‌بندی جدول‌ها
docs/                   خروجی build و همان GitHub Pages
```
